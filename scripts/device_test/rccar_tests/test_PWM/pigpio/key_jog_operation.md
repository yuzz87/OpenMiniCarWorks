# key_jog.py 操作手順

`key_jog.py` は、キーボード入力でRCカーの速度とステアリングを調整するための実機テスト用スクリプトです。`g` キーで3秒間だけ直進し、その後は速度とステアリングを中立に戻します。

## 前提

- Raspberry Pi上で実行します。
- `pigpio` がインストールされている必要があります。
- 実行前に `pigpiod` を起動します。
- PWM出力はBCM GPIO番号で、速度がGPIO12、ステアリングがGPIO13です。
- PWM周波数は70 Hzです。
- スクリプト内の速度・ステアリング指令は duty 比[%]です。

## 安全確認

実車で試す前に、必ず次を確認してください。

- 駆動輪を床から浮かせる。
- モータ電源をすぐ切れる状態にする。
- ESC、ステアリング、Raspberry PiのGNDを共通にする。
- GPIOへ5 V信号を直接入れない。
- GPIOや3.3 Vピンからモータやサーボへ給電しない。
- `PWM_CruiseSpd`、中立値、ステアリング方向が実車に合っているか低速で確認する。

## 起動手順

1. Raspberry Piでターミナルを開きます。
2. `pigpiod` を起動します。

```bash
sudo pigpiod
```

3. スクリプトのあるディレクトリへ移動します。

```bash
cd scripts/device_test/rccar_tests/test_PWM/pigpio
```

4. スクリプトを実行します。

```bash
python3 key_jog.py
```

## キー操作

| キー     | 動作                                        |
| -------- | ------------------------------------------- |
| `g`      | ステアリング中立で3秒直進し、その後中立停止 |
| `w`      | 速度指令を小さくする                        |
| `s`      | 速度指令を大きくする                        |
| `a`      | ステアリングを左方向へ動かす                |
| `d`      | ステアリングを右方向へ動かす                |
| `n`      | 速度とステアリングを中立へ戻す              |
| `Space`  | 速度とステアリングを中立へ戻す              |
| `x`      | 速度とステアリングを中立へ戻す              |
| `Enter`  | 中立へ戻して終了                            |
| `Ctrl-C` | 中立へ戻して終了                            |

3秒直進中も、`n`、`Space`、`x`、`Enter` でキャンセルできます。

## 現在の主な設定値

| 項目                  |    値 | 単位・説明                                       |
| --------------------- | ----: | ------------------------------------------------ |
| `PWM_Hz`              |    70 | Hz                                               |
| `PWM_NeutralStr`      | 10.00 | ステアリング中立 duty 比[%]                      |
| `PWM_NeutralSpd`      | 10.48 | 速度中立 duty 比[%]                              |
| `PWM_CruiseSpd`       | 11.88 | 3秒直進時の速度 duty 比[%]                       |
| `CRUISE_SPEED_OFFSET` |   1.4 | 3秒直進時の中立からの差分 duty 比[%]             |
| `STRAIGHT_RUN_SEC`    |   3.0 | 直進時間[秒]                                     |
| `SPEED_JOG_STEP`      |  0.05 | `w` / `s` 1回あたりの速度変化 duty 比[%]         |
| `STEER_JOG_STEP`      |  0.40 | `a` / `d` 1回あたりのステアリング変化 duty 比[%] |

## 終了時の動作

通常終了、`Ctrl-C`、例外発生時のいずれでも、最後に速度とステアリングを中立へ戻します。`pi.stop()` は呼び出していないため、スクリプト終了直前に中立信号を出した状態で終わります。

## 調整時の注意

`CRUISE_SPEED_OFFSET`、`PWM_NeutralSpd`、`PWM_NeutralStr` は車両固有の校正値です。値を変更すると車両が急に動く可能性があるため、変更後は必ず駆動輪を浮かせた状態で確認してください。

## 実機で確認する校正値

`key_jog.py` の表示値は PWM の duty 比[%]です。`PWM_Hz = 70` の場合、パルス幅は次の式で換算できます。

```text
パルス幅[us] = duty比[%] * 142.857
```

内容を
例えば `10.55 %` は約 `1507 us`、`10.88 %` は約 `1554 us` です。

### ステアリング

ステアリングは、前輪がまっすぐになる中立値と、機械的に無理のない左右限界を確認します。

1. 駆動輪を床から浮かせます。
2. `key_jog.py` を実行します。
3. `n` を押して速度とステアリングを中立へ戻します。
4. 前輪がまっすぐか確認します。
5. まっすぐでない場合は `a` / `d` で少しずつ調整します。
6. 表示される `str` の値を記録します。

左右限界は、サーボが唸る、リンケージが突っ張る、タイヤがシャーシに当たる、またはそれ以上角度が増えない位置の手前で止め、そのときの `str` の値を記録します。`a` / `d` のどちらが左または右になるかは、実車の動きで確認してください。

記録例:

```text
ステアリング中立: 10.88 % = 約 1554 us
ステアリング左限界: 8.56 % = 約 1223 us
ステアリング右限界: 12.04 % = 約 1720 us
```

### ESC

ESCは、モーターが停止する中立値と、低速で前進・後退し始める値を確認します。必ず駆動輪を床から浮かせ、すぐに電源を切れる状態で作業してください。

1. `key_jog.py` を実行します。
2. `n` を押して速度とステアリングを中立へ戻します。
3. モーターが停止していることを確認します。
4. `w` または `s` を1回ずつ押して、タイヤがゆっくり回り始める値を探します。
5. 表示される `spd` の値と、実際の回転方向を記録します。

車両やESCの設定によって、`w` と `s` のどちらが前進になるかは変わります。RCカー用ESCでは、後退に入る前にブレーキ動作が必要な場合があります。

記録例:

```text
ESC中立: 10.55 % = 約 1507 us
低速前進開始: 10.84 % = 約 1549 us
低速後退開始: 10.26 % = 約 1466 us
```

### シミュレーション用の追加測定

F1TENTH Gym などの車両シミュレータへ接続する場合、PWM の duty 比[%]やパルス幅[us]ではなく、ステアリング角[rad]と速度[m/s]が必要になります。そのため、実機で確認した duty 比[%]に対して、実際のステアリング角と速度を追加で測定します。

#### ステアリング duty 比[%]と実ステアリング角[rad]

ステアリングは、前輪の向きを実測して duty 比[%]とステアリング角を対応付けます。角度は最初に度[deg]で測り、最後にラジアン[rad]へ変換して記録します。

```text
steer_angle[rad] = steer_angle[deg] * pi / 180
```

記録例:

```text
str_duty[%], steer_angle[deg], steer_angle[rad]
10.88, 0, 0.000
10.30, -8, -0.140
9.72, -16, -0.279
11.46, 8, 0.140
12.04, 16, 0.279
```

左右の符号は実車の座標系に合わせます。`ellipse_run` では通常、左旋回を正、右旋回を負として扱うか、`STEER_SIGN` で向きを補正します。

#### ESC duty 比[%]と実速度[m/s]

ESCは、一定の duty 比[%]で直線走行させ、既知の距離を進む時間から速度を計算します。低速から始め、広い場所で、すぐ停止できる状態で測定してください。

```text
speed[m/s] = distance[m] / time[s]
```

記録例:

```text
spd_duty[%], distance[m], time[s], speed[m/s]
10.55, 0.0, -, 0.00
10.84, 1.0, 4.8, 0.21
11.13, 1.0, 3.1, 0.32
11.40, 1.0, 2.2, 0.45
```

同じ duty 比[%]で複数回測定できる場合は、平均速度を使います。床面、バッテリー電圧、タイヤの滑りで速度は変わるため、この表は車両固有の近似値として扱います。

#### duty 比[%]から物理量へ変換するアダプタ

測定した表を使い、実機用の duty 比[%]をシミュレータ用のステアリング角[rad]と速度[m/s]へ変換します。最初は線形補間で十分です。

```python
STEER_TABLE = [
    (10.30, -0.140),
    (10.88, 0.000),
    (11.46, 0.140),
]

SPEED_TABLE = [
    (10.55, 0.00),
    (10.84, 0.21),
    (11.13, 0.32),
    (11.40, 0.45),
]
```

変換後は、シミュレータへ次のような物理量として渡します。

```text
steer_rad = duty_to_steer_rad(str_duty)
speed_mps = duty_to_speed_mps(spd_duty)
```

この変換は、PWM/GPIOの実機確認を置き換えるものではありません。シミュレータ上で走行ロジックを試すために、実機の校正値を物理量へ近似変換するためのものです。

### GPIO番号と電源構成

実際に動いた配線を、BCM GPIO番号と物理ピン番号の両方で記録します。

| 機能             | BCM GPIO | 物理ピン |
| ---------------- | -------: | -------: |
| ESC信号          |       12 |       32 |
| ステアリング信号 |       13 |       33 |

電源構成も次のように記録します。

```text
Raspberry Pi:
USB-C電源または専用電源から給電

ESC:
走行用バッテリーから給電

ステアリングサーボ:
ESC内蔵BECまたは外部BECから給電

GND:
Raspberry Pi、ESC、サーボ電源のGNDを共通化
```

GPIOは信号用です。モーターやサーボを Raspberry Pi の GPIO や `3.3 V` ピンから給電しないでください。また、`5 V` 出力のエンコーダ信号を Raspberry Pi の GPIO へ直接入力せず、`3.3 V` 対応出力またはレベルシフタを使用してください。

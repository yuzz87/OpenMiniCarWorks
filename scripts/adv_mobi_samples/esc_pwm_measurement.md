# ESC と PWM パルス幅の実測メモ

このメモは、`demo.py` や `key_jog.py` で使う ESC、サーボ、PWMパルス幅[us]の意味と、実機で校正値を調べる方法をまとめたものです。

## ESCとは

ESC は `Electronic Speed Controller` の略で、モーターの回転を制御する部品です。

Raspberry Pi はモーターを直接動かしません。Raspberry Pi は ESC へ制御信号を送り、ESC がバッテリー電力を使ってモーター電流を制御します。

```text
Raspberry Pi GPIO
  -> ESC信号線
  -> ESC
  -> モーター電流を制御
  -> モーターが回る
```

モーターの電力は、走行用バッテリーから ESC 経由で供給します。Raspberry Pi の GPIO や `3.3 V` ピンからモーターへ給電してはいけません。

## usとは

`us` は `microsecond`、マイクロ秒を表す単位です。本来の記号は `µs` ですが、コードやASCIIテキストでは `us` と書くことが多いです。

```text
1 us = 0.000001 s
1000 us = 1 ms
1500 us = 1.5 ms
2000 us = 2 ms
```

`demo.py` の次のコードでは、ESC信号のHigh時間を `1500 us` にしています。

```python
pi.set_servo_pulsewidth(THROTTLE_PIN, 1500)
```

## PWMパルス幅とは

PWM信号では、一定周期で信号を繰り返し、その中で High になっている時間を変えます。この High の時間がパルス幅です。

RCサーボやRCカー用ESCでは、おおよそ次の範囲が使われます。

```text
1000 us 付近: 片側最大
1500 us 付近: 中立
2000 us 付近: 反対側最大
```

ステアリングサーボの場合:

```text
1500 us: 中央付近
1000 us側: 左または右
2000 us側: 反対方向
```

ESCの場合:

```text
1500 us: 停止/ニュートラル
1000 us側: 前進または後退
2000 us側: 反対方向
```

どちら側が前進、後退、左、右になるかは、ESC、サーボ、配線、リンケージ方向によって変わります。

## 1500 us が中立として使われる理由

`1500 us` は、RC受信機やRCサーボで長く使われている標準的な中心値です。多くのサーボやESCは、`1000 us` から `2000 us` 付近の信号を受け取り、その中央である `1500 us` 付近を中立として扱います。

ただし、実機では完全に `1500 us` が真の中立とは限りません。

例えば、実車では次のようにずれることがあります。

```text
ESC中立: 1507 us
ステアリング中立: 1554 us
```

このずれは、サーボの個体差、ESCのキャリブレーション、リンケージの取り付け、車体の組み付け状態によって変わります。

## 実測値を調べる方法

実測値は、次の2通りで確認できます。

## 1. 実車の反応から調べる

実用上は、この方法が一番重要です。測定器がなくても調べられます。

### ステアリング中立

```text
1. 駆動輪を床から浮かせる。
2. サーボ電源を入れる。
3. ステアリングのパルス幅を少しずつ変える。
4. 前輪がまっすぐになる値を記録する。
```

記録例:

```text
ステアリング中立: 1554 us
左限界: 1223 us
右限界: 1720 us
```

### ESC中立と低速前進

```text
1. 駆動輪を床から浮かせる。
2. ESCとモーター電源を入れる。
3. 1500 us付近から少しずつ変える。
4. モーターが完全に止まる値を記録する。
5. ゆっくり前進し始める値も記録する。
6. 必要なら、ゆっくり後退し始める値も記録する。
```

記録例:

```text
ESC中立: 1507 us
低速前進開始: 1549 us
低速後退開始: 1466 us
```

RCカー用ESCでは、後退に入る前にブレーキ操作が必要な場合があります。その場合、単純に中立より小さい値または大きい値を送っても、すぐには後退しないことがあります。

## 2. 測定器で信号を測る

Raspberry Pi が実際に出しているPWM信号を確認するには、測定器を使います。

使えるもの:

```text
オシロスコープ
ロジックアナライザ
サーボテスター
```

測る対象は、PWM信号が High になっている時間です。

```text
High時間 = 1500 us なら中立相当
High時間 = 1450 us なら中立より小さい側
High時間 = 1550 us なら中立より大きい側
```

測定器で分かるのは、Raspberry Pi が何 `us` の信号を出しているかです。その値で車がまっすぐ進むか、モーターが止まるかは、最終的に実車で確認する必要があります。

## duty比[%]からusへ換算する方法

`key_jog.py` のように duty比[%]でPWMを指定する場合、パルス幅[us]へ換算します。

```text
パルス幅[us] = duty比[%] / 100 * 1,000,000 / 周波数[Hz]
```

PWM周波数が `70 Hz` の場合:

```text
パルス幅[us] = duty比[%] * 142.857
```

例:

```text
10.55 % = 約 1507 us
10.88 % = 約 1554 us
```

`demo.py` のように `set_servo_pulsewidth()` を使う場合は、最初からパルス幅[us]を指定します。

```python
pi.set_servo_pulsewidth(THROTTLE_PIN, 1500)
```

## 安全確認

- 最初は必ず駆動輪を床から浮かせる。
- すぐにモーター電源を切れる状態で作業する。
- Raspberry Pi、ESC、サーボ電源の GND を共通にする。
- モーターやサーボを Raspberry Pi の GPIO や `3.3 V` ピンから給電しない。
- 5 V出力のエンコーダ信号を Raspberry Pi GPIOへ直接入力しない。
- パルス幅は小さく少しずつ変える。
- 実測した中立値、低速前進値、左右限界値を記録してから自律走行側へ反映する。

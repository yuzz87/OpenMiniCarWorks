# エンコーダ床走行試験結果

実施日: 2026-07-13

## 目的

車両を床に置いた状態で、ESC Duty比と走行開始条件、車輪周速度、累積距離、中立復帰を確認する。

## 使用ファイル

リポジトリ側:

```text
scripts/device_test/rccar_tests/test_encoder/key_jog_encoder_floor.py
```

Raspberry Pi側:

```text
~/OpenMiniCarWorks/scripts/encoder/key_jog_encoder_floor.py
```

出力されたログ:

```text
~/OpenMiniCarWorks/scripts/encoder/key_jog_encoder_floor_log.csv
```

## 試験設定

| 項目 | 値 |
|---|---:|
| ESC信号 | BCM GPIO 12 |
| ステアリング信号 | BCM GPIO 13 |
| PWM周波数 | 70 Hz |
| ESC中立 | 10.300 % |
| ステアリング中立 | 10.895 % |
| Duty刻み | 0.020 % |
| エンコーダA相 | BCM GPIO 22 |
| エンコーダB相 | BCM GPIO 27 |
| カウント数 | 36 count/rev |
| タイヤ直径 | 0.066 m |
| 1カウント距離 | 約0.005759587 m |
| 時間上限 | 10.0 s |

前進専用試験として、A相立ち上がりを常に正方向へ数えた。B相による回転方向判定は使用していない。

## ユーザーによる実車観察

```text
ESC Duty 10.16 %で車両が完全に走り始めた。
10.16 %のまま維持し、それより強い出力には進めず停止した。
```

この観察を床上の走行開始判定として優先する。

## Duty比ごとの結果

| ESC Duty比 | ログと実車の状態 |
|---:|---|
| 10.280 % | カウント変化なし |
| 10.260 % | カウント変化なし |
| 10.240 % | カウント変化なし |
| 10.220 % | カウント変化なし |
| 10.200 % | 1カウントのみ。連続走行ではない |
| 10.180 % | 合計2カウントまでの微小変化。連続走行ではない |
| **10.160 %** | **正カウントが連続して増加し、実車も完全に走行開始** |
| 10.140 %以下 | 今回は床上で試験していない |

## 10.16 %での速度

`10.160 %`指令後、速度は低速から徐々に上昇した。

```text
最初に有効な速度が出た時点: 約0.043 m/s
終盤のおおよその範囲:       約0.36〜0.39 m/s
終盤の代表値:               約0.37 m/s
提供ログ内の最大値:         約0.392 m/s
```

したがって、今回の床条件と車両状態では次を暫定値とする。

```text
ESC Duty 10.16 % -> 車輪周速度 約0.37 m/s
```

これはエンコーダから計算した車輪周速度であり、Motive等で測定した車体速度ではない。タイヤの空転がなければ車体速度に近いが、完全には一致しない可能性がある。

先輩のMPCコードにある参照速度`v_ref = 0.4 m/s`に近いが、MPCの速度入力`v [m/s]`とESC Duty比`[%]`を直接同一視してはならない。

## 距離と停止結果

時間上限直前のログ:

```text
elapsed_s             = 9.993531 s
ESC Duty              = 10.160 %
encoder_count         = 345
encoder_distance      = 1.987057353 m
encoder_speed         = 0.355163959 m/s
```

中立復帰後の最終ログ:

```text
event                 = neutral_exit:time_limit
elapsed_s             = 11.005274 s
ESC Duty              = 10.300 %
steering Duty         = 10.895 %
encoder_count         = 360
encoder_distance      = 2.073451151 m
encoder_speed         = 0.000000000 m/s
pulse_age             = 0.613792 s
```

中立指令後の車輪回転差:

```text
360 - 345 = 15 count
15 count x 約0.005759587 m/count = 約0.0864 m
```

この約`0.0864 m`は、中立指令後にエンコーダで観測された車輪回転相当距離である。実際の車体惰性距離とは一致しない可能性がある。

## 判定

- `r`によるarmは正常に動作した。
- `w`によるDuty変更は正常に動作した。
- 床走行中もカウントは正方向へ連続して増加した。
- 高速リフト試験で発生していた速度符号の交互反転は発生しなかった。
- `10.16 %`で床上の連続走行を確認した。
- 時間上限でESCとステアリングが確認済み中立値へ戻った。
- 最終速度は`0 m/s`になった。

今回の床走行試験は合格とする。

## 現在の暫定校正値

```text
ESC neutral              = 10.300 %
steering neutral         = 10.895 %
floor continuous motion  = 10.160 %
wheel speed at 10.160 %  = 約0.37 m/s
```

`10.16 %`は、この車両、今回のバッテリー状態、床面、タイヤ荷重における暫定値である。条件が変わると走行開始Duty比と速度も変化する可能性がある。

## 今回確認していないこと

- `10.14 %`、`10.12 %`、`10.10 %`での床走行
- 後退方向と後退速度
- Motiveによる実車速度・実移動距離との比較
- ステアリング操作中の速度
- MPCによる目標位置追従と停止

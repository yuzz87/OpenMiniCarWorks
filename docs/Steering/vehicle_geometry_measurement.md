# 車両寸法・ステアリング幾何の測定方法

## 目的

新しい機体で制御に必要な車両寸法とステアリング幾何を取得する方法をまとめる。

測定値は実験メモではmmやdegで記録してよいが、制御コードではSI単位を使う。

```text
長さ: m
角度: rad
```

## 対象項目

| 項目 | 記号 | 例 | コード用単位 |
| --- | --- | ---: | --- |
| ホイールベース | `L` | `235 mm` | `0.235 m` |
| トレッド | `T` | `170 mm` | `0.170 m` |
| タイヤ直径 | `d` | `68.5 mm` | `0.0685 m` |
| サーボセンター角 | - | `90 deg` | `1.5708 rad` |
| 旋回角度1 | `theta_1` | `45 deg` | `0.7854 rad` |
| 旋回角度2 | `theta_2` | `30 deg` | `0.5236 rad` |
| 最小旋回半径 | `R` | `469 mm` | `0.469 m` |

注意: 表で `タイヤ直径 r` と書かれていても、値が `68.5 mm` なら一般的なRCカーでは半径ではなく直径の可能性が高い。半径が必要な場合は次を使う。

```text
tire_radius_m = tire_diameter_m / 2
```

## 1. ホイールベース L

### 測る場所

ホイールベースは、後輪軸中心から前輪操舵軸中心までの距離である。

```text
L = 後輪軸中心から前輪操舵軸中心までの距離
```

前輪のタイヤ接地点中心ではなく、操舵で回転する軸の中心を基準にする。

### 測定方法

1. 車両を水平な机または床に置く。
2. 後輪軸の中心線を紙やテープでマークする。
3. 前輪の操舵軸中心を左右で確認する。
4. 後輪軸中心線から前輪操舵軸中心までを定規またはノギスで測る。
5. mmで記録し、コードではmへ変換する。

変換:

```text
wheelbase_m = wheelbase_mm / 1000
```

## 2. トレッド T

### 測る場所

トレッドは、左右タイヤの中心間距離である。

```text
T = 左タイヤ中心から右タイヤ中心までの距離
```

前輪と後輪でトレッドが違う場合は、前輪トレッドと後輪トレッドを分けて記録する。

### 測定方法

1. 車両を上から見られる状態にする。
2. 左右タイヤの接地点中心、または左右ホイール中心を確認する。
3. 左右中心間距離を測る。
4. mmで記録し、コードではmへ変換する。

変換:

```text
track_m = track_mm / 1000
```

## 3. タイヤ直径 d

### 測る場所

タイヤ外径を測る。

```text
d = タイヤ外径
```

### 測定方法

1. タイヤを取り付けた状態で外径を測る。
2. ノギスが使える場合はノギスで測る。
3. タイヤが柔らかい場合は強くつぶさない。
4. 左右で差がある場合は平均値を使う。

変換:

```text
tire_diameter_m = tire_diameter_mm / 1000
tire_radius_m = tire_diameter_m / 2
```

## 4. サーボセンター角

### 意味

サーボ中立時に、サーボホーンが基準線に対して何度になっているかを確認する。

一般的には `90 deg` 付近を中立にする。

### 測定方法

1. ステアリング中立PWMを出す。
2. サーボホーンの向きを確認する。
3. サーボホーンがリンケージに対して無理な角度でないか確認する。
4. 必要ならサーボホーンを差し直して、機械的な中立を合わせる。

角度変換:

```text
servo_center_rad = servo_center_deg * pi / 180
```

## 5. 旋回角度 theta_1, theta_2

### 意味

ステアリングを切ったときの左右前輪角を測る。

アッカーマン機構では、内輪と外輪で角度が異なる。

```text
theta_1 = 内輪側の前輪角
theta_2 = 外輪側の前輪角
```

どちらを `theta_1`、`theta_2` と呼ぶかは、実験メモ内で統一する。

### 測定方法

1. 車体の下に紙を敷く。
2. 車体中心線を紙に引く。
3. ステアリングを最大まで切る。
4. 左右前輪の向きを紙に線で写す。
5. 車体中心線と各前輪方向線の角度を分度器で測る。
6. 左右それぞれの角度を記録する。
7. 反対方向にも最大まで切って同じ測定を行う。

記録例:

```csv
direction,inner_wheel_angle_deg,outer_wheel_angle_deg,memo
left,45,30,
right,45,30,
```

角度変換:

```text
theta_rad = theta_deg * pi / 180
```

## 6. 最小旋回半径 R

### 意味

ステアリングを最大まで切ったときに、車両が描く最小円の半径である。

制御では、車両が追従できる曲率の上限を決めるために使う。

```text
curvature_max_1pm = 1 / min_turn_radius_m
```

### 方法A: 幾何から概算する

単純な自転車モデルでは次で概算する。

```text
R = L / tan(delta)
```

ここで、

```text
R     : 最小旋回半径 [m]
L     : ホイールベース [m]
delta : 代表ステア角 [rad]
```

例:

```text
L = 0.235 m
delta = 30 deg = 0.5236 rad
R = 0.235 / tan(0.5236) = 0.407 m
```

ただし、実車ではタイヤすべり、リンケージ、接地摩擦、左右輪角の違いがあるため、これは概算である。

### 方法B: 実走から求める

モーションキャプチャーが使える場合は、実走軌跡から求める方法がよい。

1. マット上で低速にする。
2. ステアリングを一定値に固定する。
3. 数秒だけ円弧走行する。
4. モーションキャプチャーで `x [m]`, `y [m]` を記録する。
5. 軌跡に円をフィットする。
6. 円の半径を `R [m]` とする。

実走から得た半径は、制御上の有効な旋回半径として扱える。

## 7. 有効ステア角への変換

実走で得た旋回半径から、有効ステア角を求める。

```text
curvature_1pm = 1 / turn_radius_m
effective_steer_rad = atan(wheelbase_m * curvature_1pm)
```

この `effective_steer_rad` は、走行制御で使うステアリング同定に使える。

## 測定シート

```csv
item,value_mm,value_deg,value_m,value_rad,memo
wheelbase_L,235,,0.235,,

servo_center_angle,,90,,1.5708,
theta_1,,45,,0.7854,
theta_2,,30,,0.5236,
min_turn_radius_R,469,,0.469,,
```

## 注意

- 長さはコードではmを使う。
- 角度はコードではradを使う。
- タイヤ直径とタイヤ半径を混同しない。
- 静止状態の前輪角と、走行中の有効ステア角は一致しない場合がある。
- マット上で走行するなら、最終的にはマット上の実走データを優先する。

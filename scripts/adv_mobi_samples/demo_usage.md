# demo.py 使い方メモ

`demo.py` は、Raspberry Pi 上で `pigpio` を使い、ステアリングサーボと ESC へ直接パルス幅を出す走行デモ用スクリプトです。

実行すると車両が動く可能性があります。最初は必ず駆動輪を床から浮かせ、すぐにモーター電源を切れる状態で確認してください。

## 前提

- Raspberry Pi 上で実行する。
- `pigpio` がインストールされている。
- 実行前に `pigpiod` が起動している。
- Raspberry Pi、ESC、サーボ電源の GND が共通になっている。
- モーターやサーボを Raspberry Pi の GPIO や `3.3 V` ピンから給電しない。

`demo.py` の現在のGPIO設定は次の通りです。

| 機能                   | BCM GPIO |
| ---------------------- | -------: |
| ステアリングサーボ信号 |       13 |
| ESC信号                |       12 |

実機調整済みの配線が別GPIOの場合、この値を確認してから実行してください。

## 実行方法

```bash
cd /home/ubuntuyuzz/Desktop/OpenMiniCarWorks/scripts/adv_mobi_samples
sudo pigpiod
python3 demo.py
```

現在の `run()` は中立信号を出すだけです。

```python
def run():
    neuteral()
    # circle()
    # forward_three_seconds()
    # zigzag()
```

走行デモを動かす場合は、使いたい関数のコメントを1つだけ外します。

例:

```python
def run():
    neuteral()
    forward_three_seconds()
```

## デモ関数

| 関数                      | 内容                                           |
| ------------------------- | ---------------------------------------------- |
| `circle()`                | 一定ステアリング、一定スロットルで走り続ける。 |
| `forward_three_seconds()` | 3秒だけ前進して、中立へ戻して終了する。        |
| `zigzag()`                | 前進しながら左右にステアリングを切り替える。   |
| `neuteral()`              | ステアリングとスロットルを中立へ戻す。         |

## パルス幅とは

パルス幅は、サーボやESCに送るPWM信号が High になっている時間です。単位は `us`、マイクロ秒です。

RCサーボやESCでは、おおよそ次のように扱います。

```text
1500 us: 中立
1500 usより小さい: 片方向
1500 usより大きい: 反対方向
```

ただし、どちらが前進・後退・左・右になるかは、ESC、サーボ、配線、リンケージ方向によって変わります。

`demo.py` では、`set_servo_pulsewidth()` の第2引数がそのままパルス幅[us]です。する方法

```python
pi.set_servo_pulsewidth(ピン番号, パルス幅_us)
```

現在の主な値は次の通りです。

```python
STEER_NEUTRAL_US = 1555.7
THROTTLE_NEUTRAL_US = 1507.1
accel = 50
steer = 200
```

そのため、スロットルのデモ出力は次のようになります。

```text
中立: 1507.1 us
前進側として使っている値: 1507.1 - 50 = 1457.1 us
```

ステアリングのデモ出力は次のようになります。

```text
中立: 1555.7 us
片側: 1555.7 + 200 = 1755.7 us
反対側: 1555.7 - 200 = 1355.7 us
```

## duty比[%]との違い

`key_jog.py` のように duty比[%]でPWMを指定するコードでは、パルス幅[us]へ換算する必要があります。

```text
パルス幅[us] = duty比[%] / 100 * 1,000,000 / 周波数[Hz]
```

PWM周波数が `70 Hz` の場合は、次のように近似できます。

```text
パルス幅[us] = duty比[%] * 142.857
```

例:

```text
10.55 % = 約 1507 us
10.88 % = 約 1554 us
```

`demo.py` は duty比[%]ではなく、最初からパルス幅[us]を指定しています。

## 安全確認

- 最初は `neuteral()` だけ実行する。
- 走行デモは駆動輪を浮かせて確認する。
- GPIO番号が実機配線と一致しているか確認する。
- 中立パルス幅が実機のESC/サーボに合っているか確認する。
- スロットル方向が逆の場合、`1500 - accel` が後退側になる可能性がある。
- Ctrl-C時に中立へ戻るが、物理的な電源カット手段も用意する。

# ステアリング接地状態・走行中同定計画

## 目的

浮遊時に作成したステアリングduty比[%]と前輪角度[deg]、[rad]の対応が、実際の走行条件である床上・マット上でも成立するか確認する。

接地時に角度が大きくずれる場合は、走行用の同定データを取り直し、制御で使う安全なステア角範囲を決める。

## 現状

想定角度と確認結果は次である。

| 条件 | 18.0 deg指令 | 9.4 deg指令 | 0.0 deg指令 | -9.0 deg指令 | -18.0 deg指令 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 想定角度 [deg] | 18.0 | 9.4 | 0.0 | -9.0 | -18.0 |
| 浮遊時の実測角度 [deg] | 18.0 | 10.0 | 0.0 | -9.9 | -19.0 |
| 地面時、マット [deg] | 10.0 | 7.0 | 0.0 | -0.5 | -11.0 |
| 地面時、板 [deg] | 16.0 | 5.5 | 0.0 | -0.5 | -9.0 |

角度の符号は、現在の制御プログラムで使う符号に合わせる。上の記録では、右方向の測定値は負角度として扱う。

## 判断

浮遊時の結果は想定角度に近いが、接地時、特にマット上では左右とも角度が小さくなっている。

このため、浮遊時の同定値だけを走行制御へ使うのはリスクがある。接地時の静的確認と、低速走行中の有効ステアリング確認を分けて行う。

## 使用する既存変換

現在のステアリング変換式は次である。

```text
steer_angle_rad = -0.186785136654 * steering_duty_percent + 2.018473280947
```

逆変換は次である。

```text
steering_duty_percent = (target_steer_rad - 2.018473280947) / -0.186785136654
```

角度変換は次である。

```text
steer_angle_rad = steer_angle_deg * pi / 180
```

現在の中立候補は次である。

```text
steering neutral duty = 10.895 %
```

ただし、線形式で `0 rad` を指令したときのduty比は次である。

```text
target_steer_rad = 0.0 rad -> steering_duty_percent = 10.806391330 %
```

この2つは区別して記録する。

## 実験A: 浮遊時の再確認

### 目的

サーボ、リンケージ、変換式が単体では正常に動くことを確認する。

これは走行用の最終同定ではなく、機械的な基準確認である。

### 条件

- 駆動輪と前輪を床から浮かせる。
- ESCは中立 duty比[%]に固定する。
- ステアリングだけを動かす。
- 物理的に電源を切れる状態にする。

### 手順

1. 車両を台に載せ、前輪が自由に動く状態にする。
2. `steering_check.py` を `USE_HARDWARE = False` で実行し、指令duty比[%]を確認する。
3. 実車出力する場合だけ `USE_HARDWARE = True` にする。
4. `n` で中立を出し、前輪が直進方向に近いか確認する。
5. 各目標角度を1つずつ出力する。
6. 前輪角度[deg]を目測または分度器で測る。
7. 異音、リンケージ干渉、サーボの苦しさをメモする。
8. 終了時にESCとステアリングを中立へ戻す。

### 記録形式

```csv
condition,target_steer_deg,target_steer_rad,command_duty_percent,measured_steer_deg,measured_steer_rad,error_deg,error_rad,memo
air,18.0,0.314159,9.124462717,18.0,0.314159,0.0,0.000000,
```

誤差は次で計算する。

```text
error_deg = measured_steer_deg - target_steer_deg
error_rad = measured_steer_rad - target_steer_rad
```

## 実験B: 静止接地時の同定

### 目的

車両を実際の走行面に置いた状態で、同じduty比[%]に対して前輪角度がどれだけ変わるか確認する。

マット上で走行するなら、マット上の静止接地データを必ず取る。板上の結果は参考値として扱う。

### 条件

- 車両をマット上に置く。
- ESCは中立 duty比[%]に固定する。
- モーターを回さない。
- ステアリングだけを動かす。
- 可能なら同じ測定を板上でも行う。

### 手順

1. マット上に車両を置く。
2. 車体中心線と前輪方向が見えるように、紙またはテープで基準線を作る。
3. `n` で中立を出し、前輪角度[deg]を測る。
4. 目標角度リストを小さい順に出す。
5. 各指令で前輪角度[deg]を測る。
6. 同じ指令を2回以上出し、戻りのばらつきを見る。
7. 左右どちらかで動きにくい、戻らない、音が苦しい場合は、そのduty比を走行用範囲から外す。
8. 板上でも比較する場合は、同じ手順で記録する。

### 推奨する目標角度

最初は現在の確認角度を使う。

```text
18.0 deg, 9.4 deg, 0.0 deg, -9.0 deg, -18.0 deg
```

角度差が大きい場合は、次の小さい角度も追加する。

```text
5.0 deg, -5.0 deg, 12.0 deg, -12.0 deg
```

### 記録形式

```csv
surface,target_steer_deg,target_steer_rad,command_duty_percent,measured_steer_deg,measured_steer_rad,error_deg,error_rad,repeat_index,memo
mat,18.0,0.314159,9.124462717,10.0,0.174533,-8.0,-0.139626,1,
board,18.0,0.314159,9.124462717,16.0,0.279253,-2.0,-0.034907,1,
```

### 判定

静止接地時に次のどれかが起きる場合、浮遊時の変換式を走行用にそのまま使わない。

- 目標角度と実測角度の差が概ね `3 deg`、約 `0.052 rad` を超える。
- 左右どちらかでほとんど角度が出ない。
- 中立へ戻したときに前輪が戻らない。
- サーボ音が大きい、またはリンケージが機械的に当たる。

## 実験C: 低速走行中の有効ステアリング確認

### 目的

実走中に車両がどれだけ曲がるかを確認し、制御で使う有効ステアリング特性を決める。

停止中の前輪角度は、接地摩擦で小さく見えることがある。実走制御では、前輪角そのものよりも、走行中の曲率または旋回半径が重要である。

### 条件

- 走行面は実験で使うマットとする。
- モーションキャプチャーで車体状態を取得する。
- 速度は低速から始める。
- 物理的に電源を切れる状態にする。
- 人がすぐ止められる広さで行う。

### 推奨する初期速度

現在の速度同定データは `0.448775 m/s` 以上であり、`0.10 m/s` や `0.30 m/s` は実測範囲外である。

最初の実走確認では、実際に安定して動く最小速度を確認してから使う。

```text
target_speed_mps = 0.3 m/s から 0.5 m/s 程度
```

ただし、速度変換式の外挿を使う場合は、必ず短時間・低duty差・安全停止可能な状態で確認する。

### 手順

1. マット上で直進低速走行を確認する。
2. 中立指令で大きく曲がらないか、モーションキャプチャーの軌跡で確認する。
3. 小さいステア角から固定指令を出す。
4. 例えば `5 deg`, `-5 deg`, `9 deg`, `-9 deg` を短時間だけ試す。
5. モーションキャプチャーから `x_m`, `y_m`, `yaw_rad`, `timestamp_s` を記録する。
6. 各固定ステア指令で、旋回半径[m]または曲率[1/m]を求める。
7. 自転車モデルから有効ステア角[rad]を推定する。
8. 機械的に苦しくなく、再現性がある範囲を走行用ステア角範囲にする。

### 有効ステア角の推定

低速で滑りが小さいと仮定すると、自転車モデルでは次の関係を使う。

```text
curvature_1pm = tan(steer_angle_rad) / wheelbase_m
```

旋回半径 `turn_radius_m` から曲率を求める。

```text
curvature_1pm = 1 / turn_radius_m
```

有効ステア角は次で求める。

```text
effective_steer_rad = atan(wheelbase_m * curvature_1pm)
```

現在のホイールベース仮定は次である。

```text
wheelbase_m = 0.25 m
```

この値は車両固有の校正値なので、実測値があれば実測値を優先する。

### 記録形式

```csv
surface,target_speed_mps,target_steer_deg,target_steer_rad,command_steering_duty_percent,esc_duty_percent,turn_radius_m,curvature_1pm,effective_steer_deg,effective_steer_rad,memo
mat,0.4,5.0,0.087266,10.339,10.15,2.80,0.357143,5.10,0.089011,
```

### 判定

走行用のステアリング範囲は、次を満たす範囲に限定する。

- 同じ指令で曲率[1/m]の再現性がある。
- 左右で大きな非対称がない、または非対称を別係数で扱える。
- サーボやリンケージに無理がない。
- モーションキャプチャーの軌跡が途切れない。
- 速度が大きく変動しすぎない。

## 走行用変換式を作り直す場合

静止接地データまたは走行中の有効ステア角データから、走行用の近似式を作る。

最初は線形近似でよい。

```text
effective_steer_rad = a * steering_duty_percent + b
```

制御で使う逆変換は次である。

```text
steering_duty_percent = (target_effective_steer_rad - b) / a
```

左右差が大きい場合は、中立を境に係数を分ける。

```text
left:  effective_steer_rad = a_left * duty + b_left
right: effective_steer_rad = a_right * duty + b_right
```

## 最終的に決める値

実験後、少なくとも次を決める。

```text
STEERING_NEUTRAL_DUTY_PERCENT
STEERING_FIT_A
STEERING_FIT_B
MAX_STEER_RAD
STEERING_SAFE_MIN_DUTY_PERCENT
STEERING_SAFE_MAX_DUTY_PERCENT
```

走行面がマットなら、マット上の結果を優先する。

浮遊時データはサーボ単体確認用として残し、走行用パラメータとは分けて管理する。

## 安全上の注意

- 接地時に角度が出ないからといって、すぐにduty比を広げない。
- サーボが保持できない角度は、制御で使わない。
- 駆動輪を床につける実験では、低速、短時間、広い場所で始める。
- 物理的に電源を切れる状態で行う。
- 終了時、例外時、通信途絶時はESCとステアリングを中立へ戻す。
